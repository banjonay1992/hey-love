# Roadmap

Work planned for Hey, Love, roughly in order.

## Next

- **Sync photos and recordings, not just metadata.** Upload media to Supabase Storage with per-user policies, resume interrupted uploads and keep everything available offline.
- **Sign in with Apple** to link an anonymous account to a real one, so memories survive a new phone.
- **Clean out the Expo starter leftovers** (template images, unused tab icons and scripts) and tighten the app bundle.
- **CI.** GitHub Actions running typecheck, lint and Jest on every push and pull request.

## Then

- **Time capsule notifications** when a locked memory opens.
- **Export and backup:** a single archive of every voice, photo and note that the user owns and can restore.
- **Accessibility pass:** VoiceOver labels on the recorder and waveform, Dynamic Type, and Reduce Motion support for the animated screens.
- **More tests** for the store, the recorder hook and the capture flow.

## Later

- **Android release** through Google Play.
- **Shared keepsake boxes** for families, invite-only and still private.
- **Home screen widget** with a memory from this day in past years.

Ideas and bugs are tracked as GitHub issues.
